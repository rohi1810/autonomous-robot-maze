
## Setup and Run

### Controller Setup
1. **Create Controller**: Make a new robot controller in C and paste the code from `rosbot.c`.
2. **Add Display**: 
   - In the Webots Scene Tree, select the robot.
   - Go to the `children` or `extensionSlot` (or select the camera section if preferred).
   - Add a new **Display** node.
   - Set the display `height` and `width` to **500**. This ensures the grid is displayed properly on screen.
